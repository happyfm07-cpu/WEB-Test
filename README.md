# AI 테스트 페이지

AI 부서에서 웹사이트 제작과 GitHub 변경 비교를 연습하기 위한 첫 번째 사이트입니다.
설치 없이 `index.html`을 브라우저에서 열면 실행됩니다.

## 파일별 역할

| 파일 | 역할 |
| --- | --- |
| index.html | 제목, 소개, 버튼 등 화면 내용 |
| style.css | 색상, 글자 크기, 화면 배치 |
| script.js | 버튼을 누를 때의 동작 |
| CHANGELOG.md | 버전별 변경 내용 |

## GitHub에 올리기

1. GitHub에서 새 저장소를 만듭니다.
2. 저장소의 파일 업로드 기능으로 이 폴더의 파일 5개를 올립니다.
3. 변경 기록 제목은 `첫 버전: 소개 페이지와 테스트 버튼 추가`로 입력합니다.
4. 이후 파일을 수정할 때마다 무엇을 바꿨는지 제목에 적습니다.
5. 저장소의 커밋 목록에서 변경 기록을 선택하면 수정 전후 차이를 볼 수 있습니다.

파일 업로드는 GitHub에 별도의 기록을 만듭니다. 로컬 Git 기록도 함께 올리려면 저장소 주소를 연결해 push해야 합니다.

## 인터넷에 공개하기

GitHub 저장소의 Settings → Pages에서 Deploy from a branch를 선택한 뒤,
업로드한 브랜치와 `/ (root)`를 지정하고 저장합니다. 배포 후 표시되는 주소에서 사이트를 열 수 있습니다.
Pages 사용 가능 여부는 저장소 공개 설정과 GitHub 요금제에 따라 달라질 수 있습니다.

## 다음 수정 연습

제목 변경이나 버튼 색상 변경처럼 작은 수정부터 시작해 보세요.
수정 후 CHANGELOG.md에 이유와 날짜를 적고 커밋하면 발전 과정을 남길 수 있습니다.
